## 1. 设计哲学与核心美学原则

在重构过程中，用户明确强调：**“设计水准要保持”**。

GlossaHub 不是一个简陋的“内部增删改查后台”，而是一个面向国际化硬件研发、跨国译员与产品专家的**高科技、专业、优雅的协作空间**。重构后的 UI/UX 设计体系恪守以下三大美学准则：
1. **沉浸式专业感（Sleek & Immersive）**：
   保留并升华备受好评的暗黑科技主题（Dark Mode 作为首选）与清爽明亮主题（Light Mode），运用深色炭黑、中性冷灰与迈金专属活力橙/极光青点缀，营造如同 IDE 与现代设计工具（如 Figma / Linear）般的沉浸专注氛围。
2. **现代微交互与玻璃质感（Glassmorphism & Micro-Interactions）**：
   统一采用 `backdrop-filter: blur(8px)` 的精细高斯模糊磨砂玻璃背景，配合 150ms~200ms 的平滑贝塞尔过渡曲线，给用户提供丝滑、有质感的按压反馈与抽屉展开体验。
3. **零卡顿的极致性能（Zero-Lag Feedback）**：
   通过虚拟滚动与原子状态下沉，实现毫秒级打字跟手响应，彻底解决大表格输入打字时的整表重渲染卡顿。

## 3. 百万级数据量零卡顿虚拟化大网格 (Manager Grid View)

```mermaid
graph LR
    subgraph 虚拟视口滚动引擎 (TanStack Virtual)
        A[数据源: 10,000+ 条全量词条] --> B[计算视口可见高度 / 滚动偏移量]
        B --> C[仅渲染视口内 25 行 DOM 节点]
        C --> D[绝对定位 translateY 支撑平滑滚动]
    end

    subgraph 行级原子响应 (Zustand + React.memo)
        E[用户在单元格高频输入打字] --> F[仅激活当前 Cell 的 Local State]
        F --> G[1.5s 防抖同步至 Zustand 原子 Store]
        G -.->|完全阻断| H[其他 24 行零重绘 零卡顿]
    end
```

### 关键实现规范：
1. **固定列与粘性布局（Sticky Columns）**：
   * 前置锁定列：锁定状态按钮、KW 键名（等宽字体）、中文基准文案（`zh_cn`）；
   * 后续动态水平滚动列：各国际语言（`EN`, `DE`, `FR`, `JA`...）；
   * 滚动时阴影过渡：表头与锁定列右侧带有平滑投影（`shadow-r`），提示用户存在横向更多内容。
2. **单元格来源与状态徽标**：
   * `ai`：左上角渲染紫色 Bot 机器图标（Hover Tooltip 显示生成模型与耗时）；
   * `tm`：左上角渲染绿色小盾牌对勾图标（表示命中记忆库，100% 可靠）；
   * `human`：纯净文本，保持整洁。

### 沉浸式工作台交互细节亮点：
1. **流式极速快捷键**：
   * `Ctrl + Enter`：保存当前翻译，自动触发后台 QA 校验，并直接跳转至下一条未翻译词条；
   * `Alt + 1` / `Alt + 2`：一键将右侧 TM 或 AI 候选译文采纳填入输入框；
   * `Alt + H`：在右侧抽屉直接展开该词条的**全量变更历史与 Git 风格前后 Diff**；
   * `Alt + D`：快速查看当前词条在基准版本中的差异比对。
2. **硬件物理尺寸进度指示器 (Hardware Constraint Bar)**：
   * 采用动态三色刻度进度条渲染在输入框右下方：`<70%` 绿条安全，`70%~95%` 黄色预警，`>100%` 红色闪烁警示。
3. **真机截图热区联动定位**：
   * 屏幕截图组件支持滚轮无级缩放与拖拽定位，聚焦词条位置带有呼吸光晕高亮边框，杜绝“盲盒翻译”。

## 5. 统一模态窗规范 GlossaModal v2

1. **标准属性遵循**：强制挂载 `role="dialog"`、`aria-modal="true"`，通过 `aria-labelledby` 绑定标题 ID。
2. **焦点捕获陷阱 (Focus Trap)**：唤起弹窗瞬间，网页焦点自动聚焦至内部第一个交互元素；用户按下 `Tab` 键时，焦点仅在弹窗内循环，禁止穿透到背景页面。
3. **Body 滚动锁定 (Body Scroll Lock)**：弹窗展开期间，自动向 `document.body` 注入 `overflow: hidden`，防止鼠标滚轮穿透滚动背景大表格。
4. **长耗时操作锁定 (`closeDisabled`)**：执行批量导入、AI 翻译流式推送等敏感异步事务时，禁用 ESC 退出与点击遮罩关闭。
